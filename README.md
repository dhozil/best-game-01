# Prism Drift
Original momentum survival arcade. Run node serve.ts and open localhost:8080. No build or external assets.
WASD/arrows move; mouse aims and fires. Fast drift leaves lethal ribbons. Choose upgrades with 1–3 between waves. Every fifth sector contains a boss. Enter starts, R restarts, M mutes, Q reduces shake.
Modules separate simulation, drawing, audio, feedback, encounters, upgrades, input, seeded math and screenshot setup. Screenshot queries: ?shot=start&seed=1, ?shot=play&seed=1, ?shot=end&seed=1.
