# Prism Drift

Prism Drift is a neon arcade survival shooter. Keep moving, aim through the chaos, and fight your way through each sector.

## Play

- WASD: move
- Mouse: aim and fire
- M: mute
- Q: reduce shake
- R: restart

## Run

Run `node serve.ts`, then open http://localhost:8080.
